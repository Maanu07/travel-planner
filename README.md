# Travel Planner AI

Phase 1 implementation of the Travel Planner AI MVP.

## Stack
- Next.js + TypeScript
- Tailwind CSS
- shadcn/ui-style components
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
